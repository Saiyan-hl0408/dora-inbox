# v0.9.7 独立源码导出差异

整理日期：2026-10-22。基于个人版 `0.9.7-personal / versionCode 27` 的当前源码工作树，采用白名单复制；没有沿用旧 `.git` 或把活跃目录直接公开。此快照保留实现，但不等同原个人加固 APK。

| 部分 | 独立导出处理 | 影响 |
| --- | --- | --- |
| 包名/版本 | `com.songoku.parcelhub.source` / `0.9.7-source`，versionCode 27 | 与个人版分开安装/存储，原签名 APK 不被覆盖；不能从原签名复现相同产物 |
| 应用标识 | 显示“ParcelHub 源码版”，人物图与字标改为中性包裹向量资源 | 布局实现保留，视觉不等同已验收人物版；源码仍有内部历史资源标识符 |
| 作者与支持 | 排除原头像、群号、收款码；作者区和支持弹窗使用已公开 GitHub 入口 | 不公开私人联系或收款素材；没有收款功能 |
| 小组件预览 | 原位图预览不公开，换中性包裹资源 | 不传播未经单独检查的截图/图片 |
| 菜鸟站点 | 默认站点为空；自动补充前无站点则跳过，手动查询提示先配置 | 需要用户在“我的”提供自己的官方站点链接，不带个人驿站上下文，不扩大查询授权 |
| 更新入口 | 上游更新 API/兜底链接指向本项目仓库 | 避免误引导安装上游 APK；本仓库无 Release 时可返回未找到，不代表有新版本 |
| 测试源码 | 保留合成 JVM 单元测试；手机号形状的拒绝样例替换成统一显式合成字面量 | 不来自实际账号，不执行拨号/提交；phone-shaped 字面量只是解析器测试输入 |
| 预览构建 | 不导出 uiPreview source set、测试 Activity/fixture、旧工作流 | 正式导航不含测试入口；本快照只提供 debug/release build type |
| wrapper | 导出目录替换为官方 Gradle 8.13 JAR 并校验官方哈希 | 修正旧 wrapper 字节与声明版本不一致；原工作区不动 |
| 许可与文档 | 独立混合许可入口、商业申请说明、来源清单、构建/功能/验证说明 | 保留上游原许可；自有新增表达商业使用须书面另行许可 |

保留且核对来源的唯一应用位图是 Apache-2.0 纸纹；其余新替代资源直接写为 Android XML 向量，并非从原人物图描摹。

源码历史排除：旧 Git 历史、`.scratch`、SDK/Gradle 缓存、`build`/`.gradle`/`.kotlin`、本机 `local.properties`、旧 APK/ZIP、加固私有副本、签名与加密材料、mapping、原运行截图、日志、账号 dump、真实运单/手机号/会话、工具探测脚本和历史交接。实际 Keystore 密钥不在源码中；`Secrets.kt` 是必要的运行时加密工具源码，保留。

用户后续要求加入核心 UI 示例及约 7MB 加固包：仅四类已检查设计示例放入 `docs/images`，不是完整图库或实际运行截图；用户指定的原加固 APK 单独作为 Release 附件，SHA-256 与原发布记录一致，不加入源码历史。分发同时附校验和及第三方许可资料，见 DOWNLOADS.md。

这次没有重写全部 MIT 基础代码。以保留其权利、清楚划分自有新增表达的方式实现商业另行授权目标；若未来要求完全独占全部代码，必须另行界定第三方替换和独立开发范围，不能用本次快照冒充全原创实现。
