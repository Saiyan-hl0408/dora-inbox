# v0.9.9-fix1 公开源码导出差异

2026-10-25，在已有 GitHub `dora-inbox` 独立目录更新，不对活跃开发目录提交或推送。来源是当前 `0.9.9 / versionCode 30` 工作树，已与最新 fix1 加固工程生成前的源文件哈希核对一致。与原 GitHub v0.9.7 的功能变化见 [../CHANGELOG.md](../CHANGELOG.md)。

| 部分 | 公开导出处理 | 影响 |
| --- | --- | --- |
| 应用ID/版本 | `com.songoku.parcelhub.source`、`0.9.9-source`、code30 | 独立安装/存储，不覆盖个人版 |
| 人物与私人素材 | 延用中性向量资源，排除人物PNG、字标、头像、群号、收款码及原小组件截图 | 源码版视觉与原加固APK不同；仍保留历史内部资源标识符 |
| 菜鸟站点 | 默认空，缺站点时跳过自动补充并在手动查询时提示设置 | 不公开个人站点上下文；用户需提供官方链接，不扩大平台授权 |
| 支持/更新入口 | 使用公开GitHub联系与本仓库更新入口 | 不带私人联系方式或误下载上游APK |
| 实验入口 | 不导出 douyinTest/uiPreview source set 与内部测试Activity | 正式BuildConfig.ENABLE_DOUYIN=false；相关业务代码可阅读，但不宣称抖音已正式支持 |
| 测试 | 保留合成JVM测试，将手机号形状样例统一为显式虚构字面量、诊断secret样例改为显式合成sentinel | 测试行为仍需通过；不带实际账号导出或原手机诊断文件 |
| 第三方渲染库 | 原样保留JsBarcode3.12.3、qrcode-generator2.0.4及其MIT头，附完整许可/固定提交证据 | 不纳入用户新增表达的商业限制 |
| 工具/许可 | 保留已核对官方Gradle8.13 wrapper、构建脚本、上游许可和商业另行授权方案 | 不公开SDK/缓存/签名/私有加固材料 |
| UI介绍 | 仅更新首页、详情、身份码、我的四类核心设计图 | 来自当前本地可编辑设计，不是运行截图、完整图库或账号验收证据 |

Git源码排除：旧Git历史、`.scratch`、build/.gradle/.kotlin、SDK/缓存、本机local.properties、APK/验收ZIP、签名和加密材料、mapping、账号dump、原始响应/诊断、真实截图/订单/手机号/Cookie/API Key。`Secrets.kt`是运行时加密工具而非实际密钥，不删除必要实现。

用户指定的最新原加固APK只作为Release附件；与交付文件哈希一致，不重新签名或加固。原APK保留个人版素材和配置，公开源码不能逐字节复现它。没有为了商业许可目标重写全部MIT基础代码；第三方权利始终优先保留。
