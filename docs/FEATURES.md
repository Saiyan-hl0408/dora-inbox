# 软件与核心 UI 图解

当前对应 **v0.9.9-fix1 / versionCode 30**。ParcelHub 面向 Android 10+，聚合本人可访问的京东快递、淘宝/菜鸟与拼多多订单、物流及取件服务。不是全国任意运单查询服务；抖音实验代码在正式版关闭。

以下仅保留四类核心 **UI 设计示例**，不是手机运行截图，不包含真实订单或有效身份码。采用现有新版可编辑设计源，按公开规则中性化人物标识和私人信息；不发布完整图库，不以图中已绑定/已取状态证明账号或扫码验收。

## 首页：按包裹展示，保留关联商品

首页按运单和包裹展示状态、商品、地点及当前可用取件信息。多笔订单转为同一个末端邮政/EMS 运单时，保留各笔商品，不再用最后一个名称覆盖其他订单；可以从“同一运单 · N 笔订单”进入全部商品。运输中、待取、最近已取依各自可靠状态和时间分类，进行中的转运不会因泛化待取标题误变为待取。

<img src="images/home-mockup.png" alt="同运单关联多订单与阅读位置恢复对应首页设计示例" width="330">

## 物流详情：全部关联商品和可信地点

显示关联订单商品、数量、图片、承运商、原运单与末端运单信息以及物流轨迹。地点优先从可信取件事件中的明确站点名称提取；“请凭码取件”等提示句不当作站点。站点、最新状态与签收时间分别处理，不用历史地点覆盖最新运输状态。缺失的数据保持未知，并保留原平台查看入口。

<img src="images/detail-mockup.png" alt="保留全部关联商品的物流详情设计示例" width="330">

## 身份码：三平台普通/放大展示

京东、菜鸟继续承载官方网页身份码，配套账号选择、重新加载、放大/缩小和原 App 备用入口。拼多多加入 App 内身份码展示，支持条码/二维码切换、服务端剩余有效期及自动更新；账号变化、失效和退出前台时按归属与生命周期清理显示，不把旧码当作新账号凭据。是否能实际取件仍需官方服务和站点扫码验收。

<img src="images/identity-mockup.png" alt="三平台新版普通出示设计图，所有码仅为无效演示字符串" width="1100">

## 我的：独立管理前台与后台更新

管理京东、拼多多、淘宝绑定与单平台同步，进入历史、同步结果和帮助。前台“自动同步”表示打开软件时更新；新增**后台定时同步**默认关闭，开启可选 15、30、60 分钟，关闭后不因标记跟踪包裹自动重启。系统电池策略、网络与后台调度可能延后执行，不保证准点。

<img src="images/my-mockup.png" alt="我的页后台定时同步15/30/60分钟选项设计示例" width="330">

菜鸟查询站点仍需用户配置自己的官方链接。历史默认北京时间近 7 个自然日、最大 180 天，范围扩大时补读未覆盖区间；返回详情/重建列表可按筛选、范围、搜索恢复阅读位置。手动/分享文本导入保留，通知监听导入已移除。

诊断支持摘要复制和完整 TXT 分享/选址保存，敏感凭据字段作脱敏处理；导出的业务信息仍应在分享前自行检查。仓库不含真实诊断原件。完整实现和网址见 [IMPLEMENTATION.md](IMPLEMENTATION.md)，更新对照见 [../CHANGELOG.md](../CHANGELOG.md)。
