# 软件与核心 UI 图解

ParcelHub / 哆啦收件箱面向 Android 10+，把本人可访问的京东快递、淘宝/菜鸟和拼多多订单、物流、取件信息汇总在一个入口。先绑定账号，再读取平台返回的可见内容；不是全国任意运单查询服务。源码公开版与可下载个人加固版的差异见 [EXPORT-CHANGES.md](EXPORT-CHANGES.md)。

以下只保留四类核心设计示例，**不是 App 运行截图，不包含真实账号数据，不代表图中各平台已在你的手机登录**。首页、物流详情和我的页从已验收的可编辑设计组件渲染，只替换人物图/字标和商品图片；身份码选取已确认图库中不含人物素材的原设计板。未发布完整图库、原人物资产、私人头像或联系方式。

## 首页：把待取信息放到一起

集中显示平台来源、商品、当前可用取件码、取件地点、到站时间、承运商与运单。取件码的提供方单独标注，不因订单来自拼多多就推断身份码必须使用拼多多。没有可靠取件码时提供查询/核验入口，不把手机号、验证码或历史码当作当前码。

<img src="images/home-mockup.png" alt="首页设计示例" width="330">

## 物流详情：核对状态与时间线

查看商品、运单、承运商与物流事件；需要更完整信息时可前往原平台。当前状态和事件时间以平台实际响应为依据，不能由设计图中的两条演示轨迹推断平台支持所有承运商。

<img src="images/detail-mockup.png" alt="物流详情设计示例" width="330">

## 身份码：进入对应官方服务

按实际取件服务打开京东或淘宝/菜鸟等身份码入口；多账号时需要选择与该包裹对应的账号。身份码由平台页面提供，本项目不凭空生成有效扫码图案。下图全部码区域都是无效示意。

<img src="images/identity-mockup.png" alt="官方身份码和账号选择设计示例" width="1100">

## 我的：绑定、同步与设置

查看京东、拼多多、淘宝的绑定状态、发起单平台同步、管理账号，并进入取件历史、同步结果/帮助和自动同步设置。菜鸟站点需在相关设置入口由用户自行配置。图中的抖音商城仅为规划中预留，**当前没有接入**；图中“已绑定”是合成设计状态，不代表实际账号已绑定或授权。

<img src="images/my-mockup.png" alt="我的页设计示例" width="330">

默认历史范围为北京时间近 7 个自然日、最多 180 天；扩展范围会根据已覆盖进度补读。当前版本移除了通知监听导入，仍保留手动/分享文本导入。实现文件和官方链接见 [IMPLEMENTATION.md](IMPLEMENTATION.md)，构建与真实设备边界见 [VALIDATION.md](VALIDATION.md)。
